# Standard 2800 — Edition 5 (Flutter)

اپلیکیشن محاسبات مقدماتی پارامترهای طیف، ضریب زلزله، برش پایه و توزیع نیروی جانبی.

## ساخت APK با GitHub Actions

1. همه محتویات این مخزن را در ریشه یک repository قرار دهید؛ `pubspec.yaml` باید در ریشه باشد.
2. پوشه `.github/workflows/` و فایل `build-apk.yml` را حفظ کنید.
3. از تب **Actions**، گردش‌کار **Build Standard 2800 APK** را اجرا کنید یا با push به شاخه `main`/`master` آن را فعال کنید.
4. پس از موفقیت، فایل `standard-2800-v5-apk` را از بخش Artifacts دریافت کنید؛ داخل آن `app-release.apk` است.

گردش‌کار در صورت نبود پوشه `android/`، فایل‌های پلتفرم اندروید را با Flutter تولید می‌کند.

## اصلاحات ایمنی ورودی

- مقادیر پیش‌فرض طبقات با ارتفاع ساختمان 15 متر سازگار شده‌اند (5 طبقه، ارتفاع‌های 3 تا 15 متر).
- ارتفاع‌ها و وزن‌های غیرمثبت و ترازهای غیرصعودی پیش از محاسبه رد می‌شوند.
- برای زمین نوع VI، مقادیر نوع IV دیگر به‌طور خودکار جایگزین نمی‌شوند؛ تعیین پارامترها به مطالعه ویژه ساختگاه نیاز دارد.
- آزمون‌های پایه محاسباتی در `test/engine_test.dart` افزوده شده‌اند.

## محدودیت مهم

این نرم‌افزار به‌تنهایی گواهی انطباق با استاندارد ۲۸۰۰ ویرایش پنجم نیست. پیش از استفاده در طراحی واقعی، تمام جداول، ضرایب، محدودیت‌های سیستم سازه‌ای، طبقه‌بندی لرزه‌ای و روابط باید با نسخه رسمی و مثال‌های مرجع کنترل و مستقل اعتبارسنجی شوند. آزمون‌های موجود فقط سازگاری عددی پایه را بررسی می‌کنند و تأیید آیین‌نامه‌ای محسوب نمی‌شوند.
